# 원샷 서클 배틀

QR로 학생들이 접속해 휴대폰에 원을 한 번에 그리고, 교사용 전자칠판에서 정확도와 순위를 공개하는 교실형 수학 게임 MVP입니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `/circle-battle`을 열면 교사용 화면이 시작됩니다. 학생용 URL은 교사용 화면의 QR 코드로 접속합니다.

## 주요 기능

- 교사용 방 생성과 QR 입장
- 학생 이름/팀 선택
- 모바일 캔버스 한 붓 원 그리기
- 자동 제출과 정확도 계산
- TOP 5, 팀 평균, 반 평균 원 오버레이
- 기준 원, 블라인드, 한 붓, 속도전 모드
